📌 Project Overview

The Hash Calculator & Password Cracker is a cybersecurity learning project designed to demonstrate how password hashing works, how hash values can be generated, and how password-cracking techniques can be used to evaluate password security.

This project provides practical exposure to password security concepts and introduces beginners to common techniques used in ethical hacking and defensive cybersecurity.

🎯 Project Objectives

- Understand password hashing and its importance in cybersecurity.
- Generate hash values from text inputs.
- Learn how password-cracking techniques work.
- Understand dictionary-based password attacks.
- Identify weak passwords and improve password security.
- Develop practical cybersecurity and ethical hacking skills.

⚙️ Key Features

- Hash Calculator: Generate hash values from text.
- Password Cracker: Demonstrate password recovery techniques against authorised test hashes.
- Hash Analysis: Examine and understand different hash formats.
- Password Security: Understand the risks associated with weak passwords.
- Cybersecurity Education: Practical introduction to password security and ethical hacking.

🛠️ Technologies Used

- Python
- Hashing Algorithms
- Password Security Concepts
- Cybersecurity Techniques


Through this project, I explored:

1. The fundamentals of cryptographic hashing.
2. How passwords are converted into hash values.
3. How password-cracking techniques operate.
4. Why weak and reused passwords create security risks.
5. The importance of strong passwords and secure password storage.
6. The role of ethical hacking in identifying security weaknesses.

🛡️ Ethical Use and Disclaimer

This project is developed strictly for educational purposes, cybersecurity research, and authorised password-security testing.

Only use this tool against hashes and systems that you own or have explicit permission to test.

Unauthorised access to accounts, systems, or protected information is illegal and is not supported.
